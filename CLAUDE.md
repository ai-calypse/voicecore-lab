# Agent operating instructions for VoiceCore Lab

**Read [`MASTER_AGENT_GUIDE.md`](MASTER_AGENT_GUIDE.md) first.** It is the canonical document index, execution runbook and source-of-truth policy.

This is a **voice AI systems engineering portfolio**; do not implement commercial DocsVoice SaaS requirements. Current specs live under `docs/`. The historical `archive/` is strictly read-only.

Do not treat planned tasks or targets as completed work. For a task, read current master plan and assigned step, inspect actual code, implement only authorized scope, run and record tests, and update `EXECUTION_STATUS.md` and the step's evidence registers.

If in doubt, obey source precedence in `MASTER_AGENT_GUIDE.md#2-authoritative-source-order` and stop at the assigned handoff gate.
